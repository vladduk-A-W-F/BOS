## Результат

Локальна реалізація A03 пройшла: 33 нові регресії, разом 115 Django-тестів; 151 функціональна та 5 launcher без регресій. Незалежний огляд дійшов консенсусу у перевіреному scope. PostgreSQL, Windows, браузер і виробничий сервер НЕ ЗАПУЩЕНО. Повний verify повернув **1**, продукт не готовий.

Зв’язок User↔Employee явний, nullable OneToOne; історичні ID збережені. Вхід і вихід використовують справжні сесії Django та CSRF. Рівно одна призначена Group визначає роль; JSON, посада й старий session role не дають повноважень. Неактивний User або архівний пов’язаний Employee втрачає доступ. Proposal перевіряє автора, сесію та поточну роль до повернення результату. Робочий інтерфейс має українську форму входу; demo створює окремих навчальних User без нових Employee.

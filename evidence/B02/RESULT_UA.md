# B02 · початковий імпорт · локальний результат

12.09.2026, версія 0.2.12-dev. Реалізацію імпорту інтегровано та перевірено на Linux / Python 3.12.14 / SQLite 3.53.1. Це локальна контрольна точка, не приймання MVP.

## Що працює

CEO завантажує JSON або CSV із manifest, перевіряє рядки, явні прив’язки й суми та погоджує один пакет. Сім типів записів охоплюють контрагентів, номенклатуру, склади, початкові партії, замовлення/рядки продажу та відкриті залишки закупівель. Навчальний шаблон містить 27 записів з ненульовими EUR/UAH/USD; валюти не складаються між собою.

Для закупівлі з минулої системи BoS переносить лише невиконану кількість. Первісні умови, прийнята до зрізу кількість, документи та строки зберігаються окремо; старі рухи не вигадуються. Контроль джерела, нова дельта та живі залишки мають окремі поля. Незмінна квитанція й повний експорт дозволяють звірити перенесення після подальших операцій.

Повтор пакета або того самого погодження не дублює бізнес-ефект. Змінений рядок із зайнятим зовнішнім ID дає конфлікт. UI зберігає лише ідентифікатори невідомого результату в поточній вкладці та перевіряє квитанцію. Дробові кількості для приймання обчислюються точно. Окрема інструкція: `docs/INITIAL_IMPORT_UA.md`.

## Докази

До реалізації: 8 методів / 10 фактичних HTTP-падінь через відсутні маршрути (`red-1.log`). У ході незалежного огляду додатково відтворено помилки типів, прив’язок, поточних цільових записів, точності Decimal та приймання тіла запиту. Після виправлень: 45/45 вузьких методів (18 B01 + 27 B02), фактичний відкат усієї транзакції при пізній SQL-відмові, контроль оригінальних байтів документа, заповнене перенесення 47 таблиць і заборона втратного відкату міграції.

Незалежні source reviews: `B02_BACKEND_REVIEW_UA.md`, `B02_UI_REVIEW_2_UA.md`; точні списки файлів та SHA — у frozen manifests. Огляд UI й перевірка Babel не заміняють браузерне приймання.

Повний прогін №22: команда `run-command.txt`, сирі журнали `verify-1/`, остаточний `verify-1/report.json`. Exit **1**, `complete=false`; всі 11 критеріїв збережені.

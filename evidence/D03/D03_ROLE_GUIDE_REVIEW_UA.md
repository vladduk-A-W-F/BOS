## Чесні межі перед остаточним комплектом

- Root ще інтегрує файли й оновлює версію 0.2.15-dev на фактичну версію D03. Manifest має бути повторно зафіксований після цих правок.
- CAPABILITIES:36 та DRAFT_NOTES:19 згадують старий текст «Про систему». Після погодженої одноабзацної root-правки цей опис потрібно синхронізувати, як root уже запланував. Поведінку UI для цього змінювати не потрібно.
- CSV має бути перевірений root фактичним parser після поточного full26. Цей звіт підтверджує відповідність прочитаній схемі та байтам прикладу, не parser green.
- 358/314/79 слів у розділах CEO/manager/observer та `page_count_verified=false` не є доказом фізичних двох сторінок. Час «30 хвилин» — план показу, не виміряна тривалість.
- Підготовлений E2E простір є передумовою ведучого, а не готовою кнопкою автопідготовки або самостійною першою серверною установкою. Відкритий F04 — відсутність підтриманого операторського bootstrap CLI — цим посібником не закритий.
- Повний verify, D01, D04 і приймання людиною залишаються окремими. Нові тести або розширення scope за результатом цього review не потрібні.

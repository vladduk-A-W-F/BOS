# A09 · часткова реалізація, не прийнято

12.09.2026. Версія 0.2.9-dev. Стек і frontend збережено. Усі операції виконано на власних синтетичних установках.

## Реалізовано

Окремий server settings/WSGI; робочий режим, автентифікація, права і CSRF; приватні документи; строгі host/origin та trusted proxy. Точні Waitress 3.0.2 і Caddy 2.11.1. Інсталятор перевіряє manifest усього коду, володіння каталогами, створює приватну venv з 33 точних залежностей, міграції, статику й порожні бізнес-таблиці. Provisioning повертає complete=false до окремого HTTPS запуску; готова установка не проходить resume повторно.

Контролер запускає тільки власні процеси, перевіряє реальну готовність свого Caddy, TLS та health. Повторний запуск не змінює базу чи приватні файли. Журнали мають рівно чотири дозволені поля; сирі повідомлення Caddy очищуються до запису.

## Фактичний red → green у прийнятих межах

Збережено попередні відмови відсутніх модулів/config/installer/runtime-status. Незалежний огляд відтворив і виправив перетин registry/source, bootstrap shadowing, hardlink у venv, повторне provision готової установки та обхід offline wheelhouse через залежність. Фактичний Caddy виявив неправильний порядок route/header; фінальний контролер також відмовляє, коли здоровий сторонній TLS endpoint приховує провал bind власного Caddy. Окремий очищувач усуває фундаментальне поле msg, яке Caddy filter не видаляє.

## Межі і наступний крок

A09 загалом НЕ ПРИЙНЯТА; паспорт релізу не створено. Ліміт спроб проблеми завеликого запиту вичерпаний, включно з помилково розпочатою додатковою спробою агента (OVERSIZE_BOUNDARY_UA.md). Подальших виправлень межі не виконувалось; обов’язковий full verify повторив той самий oracle. За §7 master v2.1 продовжується A10.

A10 має підтвердити завершення активних записів, єдиний backup бази й усіх документів, чисте відновлення, керовані оновлення/rollback. Звичайний exit 0 старого Waitress shutdown цього не доводить. Локальний consensus A09 може охоплювати лише наведені пройдені частини, не весь серверний блок чи MVP.

# A04 · адаптація інтерфейсу до серверної Policy

11.09.2026. Кандидат: `a04_frontend_candidate.html`. Патч: `a04_frontend.patch`; джерело патчу — збережена копія `a04_frontend_base.html`. Checkout не змінювався. Реальні SQLite-файли не читалися.

## Що змінено

- Спільні `bosRole`, `bosCan`, `bosCanAction`, `bosCanView` і `bosNavigation` керують видимими розділами, прямим відкриттям view та кнопками. Невідома роль стає observer. Сервер залишається єдиним джерелом дозволу; UI не замінює серверні перевірки.
- CEO зберігає фінансові екрани й HR. Для manager показано журнал реквізитів незарплатних транзакцій; Salary не запитується. Observer не запитує Transaction та Salary. Контрагенти й договори запитуються у серверній проєкції.
- Non-CEO бачить довідник співробітників з ім’ям, посадою, відділом і станом архіву. Observer отримує картки доручень, договорів і контрагентів лише для читання; рядки відкривають деталі. Manager зберігає старі форми доручень, контрагентів і договорів. Недоступні фінансові підсумки контрагентів прибрано.
- BoSHome зберігає структуру, але для non-CEO показує операційні показники, доступні замовлення, партії, доручення та реквізити рахунків. Відсутній фінансовий підсумок не перетворюється на нуль. Прострочення доручень визначається за датою доступного snapshot.
- ERPWorkspace та BoSInspector (картка запису в поточному коді) обробляють відсутність `costs`, цін для observer, собівартості та `event.result`. Рахунок без фінансових прав відкриває лише свої доступні реквізити. Для non-CEO журнал пояснює, що показує метадані події.
- CEO_ACTIONS приховані для manager; observer не бачить кнопок запису. Manager зберігає дозволені операції. Для контролю якості та запису операції підставляється власний `employee_id`, інший працівник не пропонується. Без пов’язаного працівника ці дві кнопки не показуються.
- Нові витрати в дозволених manager-операціях залишені для ручного введення за рішенням root. Приховані історичні витрати не підставляються. Це не дає доступу до ledger/HR та не змінює перелік CEO_ACTIONS.
- Download та export посилаються на явні capabilities. Документи й завантаження версій мають окремі видимі дії. Observer порівнює доступні строки й вимоги без вигаданих цін чи рекомендації за прихованою вартістю.
- Локальне сховище: `bos:<mode>:<user_id>:<role>:<key>`. Старі ключі залишаються недоторканими й автоматично не імпортуються. Нотатки, розклад, локальний чат, налаштування та галузь більше не діляться між користувачами/ролями. Кнопка очищення локального асистента очищає тільки його поточний локальний журнал; текст більше не обіцяє знищення серверних файлів.
- AuthGate і fetch wrapper не редагувалися цим підзавданням. Копія джерела вже містила частину змін root; патч їх не включає.

## Перевірено

Команди:

```text
/workspace/scratch/c7b51e996a9f/demo-check-env/bin/python tmp/a04_ui_source.py
node tmp/a04_ui_render.cjs
```

`a04_ui_source.py` створив тільки синтетичну in-memory SQLite, застосував штатні migrations/seed-команди й отримав фактичні HTTP-відповіді за 8 маршрутами для трьох ролей. Джерело: `a04_ui_source.json`.

Babel syntax і lexical references — PASS. 303 вузькі рендери компонентів — PASS, без TypeError, `undefined` або `NaN`. Включено App finance з порожнім sub, прямі bank/salaries, HR directory й ERP costs для трьох ролей. Finance з порожнім sub нормалізується до першого дозволеного підрозділу procurement; manager bank відкриває лише реквізити, observer bank дає пояснення недоступності. Окремо перевірено відмінність локальних ключів для двох user_id і трьох ролей. Результат: `a04_ui_render_result.json`.

Це чистий рендер компонентів з фактичними синтетичними HTTP-даними; ефекти React, браузерна взаємодія, screenshot, keyboard/focus та повний gate A11 не запускалися. Ці перевірки не підміняють браузерне приймання. Широкі функціональні набори не запускалися агентом.

## Потрібно root перед інтеграцією

1. У status надати boolean capabilities `finance`, `hr_private`, `write`, `view_documents`, `download_documents`, `export_workspace`, а також наявні `external_llm`. Три дозволи documents/export без явного поля консервативно приховані.
2. Накласти patch на актуальний source, зберігши паралельні зміни root. Побудувати штатний `assets/app.js` та HTML через `scripts/build_frontend.cjs`.
3. Залишкове відоме UI-FIN-CURRENCY: старі CEO Bank/Salary та суми Contract мають спільні валютні агрегати/UAH-підписи. Це попередня задача A11; цим патчем не прийнята і не прихована в звіті.
4. Деякі сервером прибрані текстові примітки у старих ERP-таблицях лишають порожню клітинку. Це не розкриття даних і не падіння; подальше компонування може прибрати зайві колонки в A11.
5. Legacy аудіо/диктофон приховано, доки `external_llm=false`; адаптер C02 не вважається перевіреним. Демонстраційні локальні календар/звітність з оригінального UI не перебудовані цією задачею.

Уточнення координатора: діагностичний рендер використовував тимчасову підміну React dispatcher (ефекти не виконувалися). Через вимогу master ці 303 випадки не зараховано до приймання, до обов’язкових тестів або до browser gate. Збережено як допоміжний аналіз автора; реальний браузер і ефекти залишаються A11. Поточний source зібрано штатним Babel без підміни runtime.

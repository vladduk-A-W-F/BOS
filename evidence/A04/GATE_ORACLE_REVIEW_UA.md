4. Справжні неточності native admin oracle — 15 випадків: anonymous login OPTIONS/PUT (2), technical login HEAD/OPTIONS/PUT (3), anonymous logout (9), technical logout OPTIONS (1). Patch вимагає незмінності даних для OPTIONS/PUT та перевіряє bytes/JSON так само, як раніше.

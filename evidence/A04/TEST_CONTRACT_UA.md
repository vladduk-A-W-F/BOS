# A04 · збереження старих тестів і нові передумови

11.09.2026. Повний Django-прогін до адаптації передумов збережено в django-before-bootstrap.log: 163 тести, рівно два падіння в старій ChatHistoryTestCase.

Перший тест читав два повідомлення без власника. За прийнятим A04 legacy NULL не належить випадковому користувачу. Fixtures тепер явно задають user та visibility_role поточного синтетичного CEO; assertion порядку ['user','assistant'] незмінний.

Другий старий тест вимагав фізичного видалення історії та файлів. Це суперечить master v2.1 «історичні дані не переписуються й не видаляються». Він зберігає свою історичну назву та HTTP запит, але замість очікування нуля перевіряє незмінні PK обох таблиць, архівний стан, зв’язок джерела, точні bytes hello і порожній власний GET. Це зміна некоректного контракту, а не приховування регресії. Чужі/legacy рядки та файли додатково перевіряє незалежний A04 набір.

Старі 151 функціональна + 5 launcher залишають свої бізнесові assertions. Чотири законні сценарні фабрики входу явно надають синтетичному User view_document/download_document/export_workspace; helper за замовчуванням capabilities не видає, тому негативні перевірки A04 залишаються без них. Навчальні документи при створенні seed мають явну classification: технічні специфікації operational, цінові пропозиції management, виписка ceo. Старі невідомі документи не відкриваються автоматично.

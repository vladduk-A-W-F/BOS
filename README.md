# BoS · Business Operating System

Приватний репозиторій робочого застосунку BoS та його інженерного плану.

## BoS 3.0 · Світле інтерактивне прев’ю

Ця гілка готує `0.3.0-dev.6`: вона зберігає узгоджене світле прев’ю, захищений монітор після входу та прийняті картки доручень. Для кожного показника монітор тепер розкриває джерело snapshot, правило обчислення, охоплення доступних поточному обліковому запису записів, бізнес-дату, час читання у цьому вікні та наступний розділ. Окремого філіального або календарного фільтра, історичного зрізу та автоматичного переходу до конкретного source record немає; час читання не є часом зміни джерела. Три синтетичні кейси показують обґрунтування строку для 500 комплектів, відвантаження лише допущеної партії та контрольований наступний крок за відкритим залишком. PDF-брошура лишається допоміжною пам’яткою; основний огляд відбувається у локальному інтерфейсі. Це не повне приймання UXD01, browser-acceptance або приймання всіх продуктових сценаріїв. Поточний встановлений runtime зафіксовано окремо у [квитанції](docs/orchestration/bos3/LOCAL_RUNTIME_RECEIPT.json); зміна коду не означає автоматичного оновлення сервера. Це не реліз 3.0.0 і не production-дозвіл. [Діюча черга](docs/orchestration/bos3/ACTIVE_WORK_PLAN_RU.md), [план і межі](docs/orchestration/BOS3_EXECUTION_RU.md), [локальна установка](docs/learning/BOS3_LOCAL_SERVER.md).

Основна гілка та прийнята історія v18 залишаються окремими, доки новий кандидат не пройде review й явне приймання.

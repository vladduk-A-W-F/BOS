# BoS · Business Operating System

Приватний репозиторій робочого застосунку BoS та його інженерного плану.

## BoS 3.0 · Локальна Передверсія 01

Ця гілка готує `0.3.0-dev.1`: інтерактивну стартову брошуру, три синтетичні сценарії фабрики метизів, серверні навчальні сесії та вузьку CRM з preview/confirm. Це не реліз 3.0.0 і не production-дозвіл. План і поточні межі: [BoS 3.0](docs/orchestration/BOS3_EXECUTION_RU.md). Запуск окремого localhost-сервера: [локальна установка](docs/learning/BOS3_LOCAL_SERVER.md).

Основна гілка та прийнята історія v18 залишаються окремими, доки новий кандидат не пройде review й явне приймання.

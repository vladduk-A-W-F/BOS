# BOS — журнал для панели владельца

Этот журнал дополняет технические STATE/QUEUE, но не заменяет их и не разрешает работы.

Текущая основная версия: BoS v18 / `0.2.18-current`, PR #8 merged в main. Нумерованный snapshot: `bos-v18-current-2026-09-26`; точные коммиты и границы проверки: [manifest](../orchestration/CURRENT_BASELINE.json), [отчёт v18](../orchestration/V18_CURRENT_RU.md). Данные: `docs/tracker/activity.json`. Исходная ветка журнала `tracking/bos-progress` включена через PR #7 и сохраняется как источник истории. Старые события журнала не переименовываются в текущие результаты.

Исполнитель обновляет только свою задачу при старте, смене этапа, блокере и завершении. Перед записью прочитать актуальный blob SHA; сохранять чужие задачи. Писать простым русским языком, время UTC ISO8601, ссылку на commit/test/report когда она есть. Допустимые статусы: planned, active, blocked, done. Слова done означают завершение конкретной карточки, не готовность системы. Не ставить done без результата. Активная запись старше 15 минут на панели считается неподтверждённой; при длительной работе обновлять журнал на значимых этапах. Завершая ход, не оставлять active, если работа не продолжается.

Не записывать пароли, токены, персональные данные или содержимое клиентских документов. GitHub CI, merge и head SHA панель читает независимо. Исполнитель не должен объявлять проверки успешными по общему зелёному workflow без проверки jobs и версии кода.

Новые сессии не подключаются к журналу автоматически. Чтобы включить их отчёты, передайте исполнителю ссылку на этот файл. Наличие записи active само по себе не доказывает работу фонового процесса.

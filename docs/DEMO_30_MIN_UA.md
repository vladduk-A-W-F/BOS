Початковий склад і гроші нульові. Стандартний запуск демо сам не створює цей E2E-простір; кнопки «запустити Gate 6» у клієнтському UI немає.

Навчальний зріз **12.09.2026**, EUR, без ПДВ. Не змінюйте дату робочої компанії й не підміняйте серверний час заради показу. Сталі коди нижче — джерела навігації; фактичні ID обираються з поточних записів, а не копіюються зі старої сесії.

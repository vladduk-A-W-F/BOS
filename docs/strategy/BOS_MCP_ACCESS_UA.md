# Доступ ІІ-клієнтів до BoS через MCP (лише читання)

Рішення власника 09.10.2026: інтеграції з іншими серверами, зокрема MCP. BoS відповідає за протоколом Model Context Protocol на адресі `/mcp/` (Streamable HTTP, відповіді JSON). Будь-який MCP-клієнт — Claude, Codex, інший — може питати про стан компанії й отримувати ті самі дані, що й екран «Моніторинг».

## Що доступно
| Інструмент | Що повертає |
|---|---|
| `monitoring_overview` | головні числа, «Потребує уваги», плитки моніторингу, стан джерел, перелік стандартних запитів |
| `standard_query` | одна таблиця з готових запитів («Прострочені замовлення», «Хто винен і скільки» тощо) |
| `order_status` | позиції замовлення (замовлено, відвантажено, залишок) і наступний крок словами |
| `source_table` | рядки підключеного джерела (файл, Google Таблиця, таблиця з іншого сервера) за збереженою відповідністю колонок і їхня свіжість; `id` — з `monitoring_overview` |

Лише читання: без записів, SQL, дій чи preview. Ключ діє як один користувач BoS і бачить рівно те, що він. Суми бачить лише керівник; спостерігач бачить у джерелах лише свіжість. `source_table` віддає збережений знімок і нічого не завантажує заново.

## Увімкнення
Без жодного ключа доступ вимкнено (`/mcp/` відповідає 404). Ключ видається лише на сервері компанії:

```
python manage.py mcp_access create --user <користувач BoS> --label "Claude на ноутбуці"
python manage.py mcp_access list
python manage.py mcp_access revoke <номер ключа>
```

Ключ показується один раз; у базі зберігається лише його SHA-256. На owner-local ключ видає Codex у керованому середовищі сервера (ті самі налаштування, що й `internal-serve`).

## Підключення клієнта
Адреса owner-local: `http://127.0.0.1:8030/mcp/`, заголовок `Authorization: Bearer <ключ>`.
- Claude Code: `claude mcp add --transport http bos http://127.0.0.1:8030/mcp/ --header "Authorization: Bearer <ключ>"`.
- Клієнти лише зі stdio (наприклад, Claude Desktop) — через міст `npx mcp-remote http://127.0.0.1:8030/mcp/ --header "Authorization: Bearer <ключ>"`.

Запити з браузера (з заголовком Origin) і вхід лише за cookie сесії не приймаються.

## Межі
Дані, які прочитав клієнт, потрапляють до того ІІ-сервісу, який ви підключили. На демо-даних це синтетика; підключення робочої бази з реальними даними — окреме рішення власника. Платних API BoS не викликає.

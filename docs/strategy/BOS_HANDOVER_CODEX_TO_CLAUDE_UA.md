## 5. Процес після передачі

1. Картка з першопричиною й allowlist → гілка Claude → PR у main українською.
2. CI: `pr-tests`, `bos4-workspaces`, `docs-budget`.
3. Перед злиттям — вердикт `bos-reviewer` у PR: `ACCEPT <sha>` або `CHANGES <sha>`. Автор не приймає власний код. CHANGES виправляються в тому ж PR.
4. Злиття: Claude — у погодженому обсязі після зеленого CI і ACCEPT. Межі, архітектуру, права, схему й секрети вливає лише власник.
5. Доставка owner-local — локальною сесією за розділом 3. Звіт власнику — до 10 рядків, питання — списком «так/ні».

Межі `AGENTS.md` діють для Claude без змін:
- лише синтетичні дані;
- без платних API;
- без production і публічного доступу без власника;
- демо без входу — лише синтетика;
- `TECHNICAL_READY` і `PILOT_ALLOWED` — `false`;
- A09/A10/A11 і P05 не обходяться;
- не більше трьох спроб на проблему;
- секрети не потрапляють ні в Git, ні в браузер.

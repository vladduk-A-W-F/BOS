# BoS · перевірка даних перед перенесенням

Команди A07 перевіряють окремі копії. Вони не перемикають робочу установку на іншу базу. Поточний стан приймання: `PROGRESS_UA.md`; результати — `evidence/A07/`. PostgreSQL потребує фактичного запуску у виділеному тестовому середовищі.

## Перевірка наявної копії

Потрібні узгоджений SQLite-знімок і відповідний каталог файлів. Знімок має бути закритим для запису, без активних WAL/SHM/journal, поза каталогом установки. Не передавайте шлях робочої бази. Попередньо створюйте копію штатним засобом SQLite backup або зупиняйте записи на час копіювання; звичайне копіювання відкритого файла не гарантує узгодженості.

```sh
python -B scripts/preflight_data.py --snapshot /absolute/private-copy.sqlite3 --media /absolute/private-media --output /absolute/new-preflight-report.json
```

Код 0 означає, що ця копія пройшла перевірку структури, типів, зв’язків, файлів і доступної предметної звірки. Код 1 або виняток означає відмову. Це ще не підтвердження перенесення, відновлення сервера чи готовності релізу.

Звіт містить ідентифікатори та фінансові підсумки; зберігайте його разом із приватною копією. У Git і CI допускаються тільки синтетичні приклади. Невідома чи неповна схема не виправляється автоматично. Значення не обрізаються, гроші не округлюються, можливі дублікати не видаляються. Однакові сума й дата потребують перевірки джерела, а не автоматичного об’єднання.

## Синтетична репетиція

Підтримуваний локальний профіль перевірки — Python 3.12 із залежностями проєкту. Вкажіть новий каталог, якого ще немає, поза каталогом установки:

```sh
python -B scripts/check_data_transfer.py --backend sqlite --output-dir /absolute/new-rehearsal
```

Сценарій сам створює нові тестові бази та файли. Спочатку виконує міграції й операції еталона: надходження, резервування, виробництво, відвантаження, рахунок, часткову оплату, повернення, зарплату, архівування та погодження документа. Потім переносить усі таблиці в іншу нову базу.

Для EUR, USD і UAH окремо перевіряються: залишок сировини 13, готової продукції 2, вартість запасу 39, собівартість виробництва 12, рахунок 15, оплата 5, борг 10, фінансовий дохід 200 і витрата 100. Це навчальні числа, не показники підприємства.

Обов’язково збігаються кількості, кожен ID/FK, значення Decimal/JSON, версії документів, бінарні дані й SHA файлів. У похідній копії перевіряються звичайний вхід через перенесену сесію, повтор виконаного погодження та фінансових команд, а також два наступні номери документів. Прийнята цільова база й джерело при цьому залишаються незмінними. Повернення до початкової копії перевіряється повторним читанням усіх фактів.

`report.json` і `child-*.log` містять результат. Відсутній результат або `complete: false` не є успіхом. Типізований пакет `bos-typed-transfer/1` — проміжний формат зі звіркою, а не резервна копія повної серверної установки.

## Межі

Відомі історичні міграції перевіряються окремими регресіями; неповне старе джерело потребує репетиції його конкретного стану. Наявні клієнтські дані не змінюються для проходження перевірки. A09/A10 окремо відповідають за установку, оновлення, резервування, відновлення та повернення попередньої версії. Нові записи після реального перемикання між базами автоматично не зливаються.

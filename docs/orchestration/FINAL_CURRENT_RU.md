## Колонки и текст

Правка UI-COLUMN-CONTENT-01 уточняет назначение колонок и устраняет повторное представление одного и того же поля. Разные поля с одинаковым текстом сохраняются с понятными подписями. Поля, суммы, права и API-контракты сохраняются. Пустые значения получают явное обозначение отсутствующих данных, ноль остаётся нулём. Точный diff и результаты проверки фиксируются вместе с продуктовым коммитом в манифесте.

Заголовки: «На складі», «Доступно для операцій», «Ще прийняти», «Рядки до виконання». В карточках номенклатура и клиент подписаны отдельно. Для отсутствующей даты показано «Не встановлено», для других пустых значений «Не вказано»; количество 0 и денежная строка 0.00 сохраняют свой формат.

## Проверка и границы

Независимые reviews двух merge-пакетов: ACCEPT_SCOPED. В первом пакете 101 импортированный файл, кроме объединённого DECISIONS, побайтово совпал с abb8845; runtime diff был пуст. Во втором пакете 15 файлов совпали с tracking/daily источниками, runtime также не изменился.

При первой merge-проверке исправлен один лишний пустой ряд в конце DECISIONS. При импорте исторического STATE стандартный whitespace check дал exit 2 на трёх CRLF-строках. Проверка с command-local `cr-at-eol` дала exit 0; исходные bytes сохранены, глобальные настройки Git не менялись.

Адресная проверка текста колонок: 4 PASS на третьем запуске нового harness; первые два FAIL сохранены. Контролируемая проверка module_views: 25 PASS. Штатная сборка frontend завершилась с exit 0. Общая lexical-проверка завершилась с exit 1 на унаследованном `getComputedStyle`; её результат не заменён успешной сборкой.

Визуальная проверка на 1440/390 не выполнена: Playwright недоступен, встроенный браузер блокирует локальный file://-пример. Скриншотов и подтверждения геометрии нет; заблокированные маршруты не обходились. Статическая проверка оркестрации: exit 0, 10 ролей, 37 карточек, 11 неизменённых gates.

Source identity и итоговый review записываются в CURRENT_BASELINE.json и `evidence/current-20260926/`. Пустой или echo-only CI не является тестированием продукта.

## Открытые границы

- Private membership actual3: исторический FAIL 7/1; v5 имеет только static review. Этот пакет не добавляет private union или неподтверждённую очередь отделов.
- Полный путь S1/S2/S3 по ролям, завершение Task с фактическим результатом и отдельный restart/reopen не принят на новом кандидате.
- Причины исторических P06 и browser payment timeout остаются открытыми. P05 и Network 3/3 не сбрасываются.
- Все 11 обязательных gates требуют доказательств для конкретного кандидата. Старые scoped PASS и пропущенные CI jobs их не закрывают.
- Общая lexical-проверка frontend возвращает exit 1 на `getComputedStyle`: прежний вызов есть уже в 207c742, а неизменённый checker не включает это имя в allowlist. Это сохранённый диагностический FAIL, не новый регресс колонок и не PASS.
- Production-установка, реальные данные, платные API, GPT и новые коннекторы не активируются этим завершением.
- Sites «Опора» остаётся отдельным артефактом. Его публикация и действующий локальный стенд этим GitHub-объединением не обновляются.

`TECHNICAL_READY=false`, `PILOT_ALLOWED=false`, `MVP=false`. «Итоговая на текущий момент» означает зафиксированный состав основной версии и известные ограничения. После публикации версия сохраняется до следующего поручения владельца.

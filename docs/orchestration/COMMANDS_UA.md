# Команди і середовища

## Готові команди підготовки
З кореня BOS, Python 3.12+: `python tools/bos_control.py status`, `context`, `plan`, `card P10-003`, `validate`.
Це локальний read-only помічник; він не є агентним runtime, не змінює стан, не запускає app/CI/API. Коди завершення: 0 для успішного читання/валідації, 2 для неповної/помилкової конфігурації. Статус BATCH_EXECUTION сам по собі не запускає команд.

## Наступна сесія Codex
Відкрити приватний `vladduk-A-W-F/BOS`, гілку `setup/bos-gpt-orchestration-20260920`. Прочитати AGENTS.md і ORCHESTRATOR_UA.md; завдання: «Прочитай актуальні STATE, QUEUE, BATCH_01_UA та AGENTS. Продовжуй дозволену чергу паралельно з незалежним review; зупиняй лише заблоковану дію або реальне рішення. Не повторюй завершені probes чи історично заборонені suites».
За наявного Codex CLI запускати його з кореня checkout, щоб завантажити `.codex/config.toml`. CLI тут не встановлений, тому цей шлях не пройшов runtime smoke. Моделі конфігурації: gpt-6-astra для головної сесії/складного review, gpt-5.6-terra для виконання; обидва GPT-сімейства доступні у поточному середовищі Work. Перевірити доступ у конкретній інсталяції перед стартом; не підмінювати невідому модель мовчки. Налаштування читання/прав успадковують обмеження середовища і не розширюють їх.

## ChatGPT / Work
Використовувати `CHATGPT_PROJECT_UA.md`, CONTEXT, STATE та поточну картку. За наявних tools оркестратор явно делегує роль, передаючи текст TOML. Без виконуваних tools готувати специфікації/review; не вигадувати запуск команд. Не копіювати ключі, БД або real media у проєктний контекст.

## Перевірки в межах конкретної картки
Python 3.12, залежності чинного requirements-ci.txt, ізольований PostgreSQL 16. Спочатку підтвердити server_version_num і синтетичний профіль. Конкретну команду targeted-регресії визначає картка після діагностики; не підміняти БД і не запускати manage.py у стандартному профілі проти історичної БД. Runtime/source SHA обчислюється чинним scripts/verify.py source_digest(), без запуску suite.
Повний verify, PostgreSQL suite, E2E, Windows, browser та GitHub workflow dispatch виконуються тільки в межах чинного дозволу й історичних обмежень. Цей документ не надає такого дозволу. Немає команди «запусти все».

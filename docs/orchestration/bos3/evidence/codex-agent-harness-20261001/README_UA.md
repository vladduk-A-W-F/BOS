# Архів прийнятого контуру агентів Codex для BoS

Це архів вихідних файлів чинного локального BOSDev, підготовлений для окремого включення sole integrator до репозиторію. Він не є новою установкою, міграцією або підтвердженням відновлення системи.

Пакет містить дев'ять точно названих файлів обв'язки/політики та сім незмінених evidence-файлів. MANIFEST.json зв'язує кожен файл із джерелом, розміром і SHA-256. Два незмінені допоміжні файли bos-flow.ps1 та bos_dev.py мають окрему класифікацію; архівування не додає їм нового code-review verdict. Історичні receipts описують свої версії, не підміняються останніми hashes.

## Використання інтегратором

1. Перевірити SHA-256 пакета за PACKAGE_SNAPSHOT.json та кожного члена за MANIFEST.json. Порівняти поточні live hashes перед майбутнім застосуванням: цей архів не перемикає систему автоматично.
2. Зберегти розпакований пакет як доказовий архів окремим docs-комітом у робочій гілці після незалежного archive review. Пропонований шлях: docs/orchestration/bos3/evidence/codex-agent-harness-20261001. Це не дозвіл на merge або зміну runtime.
3. Під час майбутнього відновлення спочатку визначити єдиний актуальний control-home, існуючий Python/Git/Codex та власника стенда. payload/setup належить D:/3/BOSDev/setup; payload/plans — D:/3/BOSDev/plans; payload/control-tools — чинному C:/Users/user/AppData/Local/BOSDev/tools. Не робити другу writable копію стану і не перезаписувати live файли без свіжої звірки.
4. Чинна проєктна конфігурація .codex і ролі вже належать канонічному репозиторію; архів не редагує їх. Обв'язка очікує існуючі observer/config/queue/ledger та запущений Codex. Їх відновлення — окремий узгоджений крок.

## Межі та стан

У пакеті немає auth-файлів, паролів, .env, баз даних, профілю браузера, Codex sessions, live observer/config/queue/ledger чи нового розкладу. Шляхи та ідентифікатори чатів у вихідних файлах — частина чинної конфігурації, не секрети доступу.

H01–H10 підтверджені лише в межах записаних версій і спостережень. Actual next від 01.10.2026 07:56:46 UTC стосується b857176; пізніший mutable operational delta вимагає свіжої звірки перед дією. П'ять синтетичних методів і два запуски команд не є продуктовою QA. Загальна готовність BoS, доставка runtime, перевірка відновлення, Git-публікація цього архіву та merge не підтверджені самим створенням ZIP.

Першоджерела зовнішніх evidence-посилань залишаються в зазначених локальних архівах; цей пакет переносить названі звіти, а не всю історію їх вкладених посилань. Під час повного відновлення не оголошувати відсутні історичні докази PASS.

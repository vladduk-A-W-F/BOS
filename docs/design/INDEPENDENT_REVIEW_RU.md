Офлайн QA использовал исключительно перехваченный origin `https://bos3.qa`, необходимый только для secure-context API браузера. Он не запускает сервер, не обращается к действующему runtime и возвращает HTTP 405 на любой не-GET API-запрос. Неизвестный GET, console/page error, document/main overflow, recovery state или видимый alert делают прогон ошибочным.
